GitHub Actions Runner Control

Safe configuration page for the workflow in this repository. This page prepares run inputs for the action; it does not remotely control arbitrary browsers.

This is a self-owned control panel for the browser automation in this repo. It does not provide arbitrary remote keyboard or mouse control to third-party browsers. The workflow remains limited to the target URL and scripts you configure here.
Use a comma-separated list, for example: script.js,script2.js
The start command dispatches the run-script workflow. The stop command shows the GitHub CLI command to cancel an active workflow run for this repo.
