GitHub Actions

Script control panel

Manage the Visit Link And Run Script workflow. GitHub will ask you to sign in and confirm actions in its own interface; this page does not store credentials or control the browser interactively.

Start / view workflow Stop a running workflow
To start: open the workflow, select Run workflow, review its inputs, then confirm. The current workflow runs for at most six hours.

To stop: open the Actions page, select the active run, and choose Cancel workflow. Cancellation is performed by GitHub, not by this static page.
Uses GitHub's built-in workflow controls. No personal access token is requested or embedded here.
